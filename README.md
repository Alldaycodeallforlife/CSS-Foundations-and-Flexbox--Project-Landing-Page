# Loop — Landing Page (The Odin Project: CSS Foundations & Flexbox)

A flexbox landing page built to the assignment spec:

- Font: Roboto
- Header / hero / footer background: `#1F2937`
- Logo text: 24px, `#F9FAF8`
- Hero heading: 48px, weight 900, `#F9FAF8`
- Hero subtext & nav links: 18px, `#E5E7EB`
- Button / CTA background: `#3882F6`
- Info section heading: 36px, weight 900, `#1F2937`
- Quote section: background `#E5E7EB`, text 36px, weight 300, italic, `#1F2937`

Open `index.html` directly in a browser, or serve the folder with any

## Deploying

Push this folder to a GitHub repository and enable GitHub Pages
(Settings → Pages → deploy from branch) to get a live link.
